# Municipal Grievance NLP Dataset & Preprocessing Report

## 1. Overview
- **Primary Dataset:** `data/processed/municipal_grievances_2400_clean.csv` (**2,400 unique rows**)
- **Out-of-Scope Dataset:** `data/processed/kaggle_out_of_scope_clean.csv` (**60 rows**)
- **Balance:** Exact **100 complaints per category per language** (8 categories x 3 languages = 2,400 rows).
- **Split Policy:** **Unsplit** intentionally so model training handles `train_test_split` and TF-IDF fitting without data leakage.

## 2. Schema
| Column | Description |
| :--- | :--- |
| `complaint_id` | Unique identifier (`COMP_0001` to `COMP_2400`) |
| `complaint_text` | Original UTF-8 complaint text (PII redacted) |
| `cleaned_text` | Normalized text generated by `src/preprocess.py` |
| `category` | One of 8 municipal grievance categories |
| `language` | `English`, `Hindi`, or `Hinglish` |
| `source_type` | `real_open_dataset`, `synthetic_generated`, or `synthetic_translation` |
| `source_reference` | Origin dataset or source record ID |

## 3. Source Transparency Breakdown
- **`synthetic_generated`:** 882 rows (Kaggle Citizen Grievance Dataset)
- **`synthetic_translation`:** 770 rows (Grounded translations from unused real ICMYC & Kaggle records)
- **`real_open_dataset`:** 748 rows (OpenCity.in: I Change My City — Bengaluru)

## 4. Quality Audit Summary
- **Missing Values:** 0 across all columns
- **Exact Duplicates:** 0
- **Near-Duplicate Pairs (>= 0.90 char n-gram cosine similarity):** 132 pairs (~5% of rows, due to city-name swaps in Kaggle templates; ~95% structurally distinct)
- **Code-Mixed Script Notes:** 48 Hinglish rows naturally mix Devanagari salutations/phrases with Roman English/Hindi.
